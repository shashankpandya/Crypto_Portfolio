01Project Brain

Crypto portfolio dashboard fused with a Web3 token dApp. Two halves that share a shell but almost no plumbing — market data is read-only and serverless-capable; the chain half is wallet-driven and indexed by a Node backend.

Why It Exists

The problem

Standard portfolio trackers show prices. Standard wallets send tokens. Neither records why a transfer happened.

The bet

Put transfer metadata (message, category, tags) on-chain inside a custom ERC20, then index the emitted events server-side so history is queryable without hammering RPC.

🔑 The one thing to remember about this architecture

There is no single request path. Three independent pipelines share a UI shell: (1) market data browser→CoinGecko, (2) chain writes browser→MetaMask→contract, (3) chain reads server→Alchemy→Mongo→REST. Debugging means first asking which pipeline.
